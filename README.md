# মুআল্লিমুল কুরআন — কুরআনিক শব্দার্থ, ব্যাকরণ ও তিলাওয়াত শিক্ষা প্ল্যাটফর্ম
### Quran Vocabulary, Morphology & Real-Time Word-Sync Recitation PWA

> **মুআল্লিমুল কুরআন (Quran Vocabulary App)** হলো কুরআনের শব্দার্থ, ব্যাকরণগত মূলরূপ (Root), পদ প্রকার (Parts of Speech) এবং ক্বারী মিশারি রাশিদ আল-আফাসীর তিলাওয়াতের সাথে মিলিসেকেন্ড-ভিত্তিক রিয়েল-টাইম শব্দ সিঙ্ক্রোনাইজেশন (Karaoke Audio Sync) শেখার একটি পূর্ণাঙ্গ, আধুনিক ও অফলাইন-বান্ধব প্রগ্রেসিভ ওয়েব প্ল্যাটফর্ম (PWA)।

---

## 🌟 প্রধান প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. ১১৪টি সূরার শব্দে শব্দে বাংলা অর্থ ও রূপতত্ত্ব (Word-by-Word Morphology)
* কুরআনের সম্পূর্ণ **১১৪টি সূরার ৬,২৩৬টি আয়াত** এবং **৭৭,৪০০+ শব্দের** প্রতিটি অংশের জন্য:
  * বিশুদ্ধ আরবি শব্দ ও উচ্চারণ
  * সংক্ষিপ্ত ও নির্ভুল ১–৩ শব্দের বাংলা অর্থ
  * ব্যাকরণগত মূল রূপ/রুট (`root`, যেমন: `علم`, `رحم`, `كتب`)
  * পদের প্রকারভেদ (`word_type`: বিশেষ্য/Noun, ক্রিয়া/Verb, বিশেষণ/Adjective, অব্যয়/Particle)
  * বাংলা অনুবাদ ও প্রাসঙ্গিক আয়াতের সম্পূর্ণ অর্থ

### ২. হোল্ড-টু-প্লে একক শব্দ অডিও (Press & Hold Word Audio)
* আয়াতে যেকোনো আরবি শব্দে **৩৬০ মিলিসেকেন্ড** চেপে ধরে রাখলে (Long Press):
  * সরাসরি সেই একক শব্দের স্পষ্ট উচ্চারণ অডিও চালু হয়
  * স্পর্শানুভূতিপূর্ণ হ্যাপটিক ভাইব্রেশন (`navigator.vibrate`) প্রদান করে
  * সোনালী পালস অ্যানিমেশন দেখায়
* সাধারণ কুইক ট্যাপে শব্দ বিস্তারিত পেজে নিয়ে যায়; হোল্ড করার সময় পেজ ন্যাভিগেশন স্থগিত থাকে যাতে ইউজার একই আয়াতে থাকেন।

### ৩. রিয়েলটাইম শব্দ সিঙ্ক ও তিলাওয়াত প্লেয়ার (Word-Level Karaoke Audio Sync)
* ক্বারী **মিশারি রাশিদ আল-আফাসী**-র সম্পূর্ণ সূরার তিলাওয়াত এবং `data/segments/` এ থাকা মিলিসেকেন্ড টাইমিং ব্যবহার করে:
  * তিলাওয়াত চলার সময় ঠিক যে মুহূর্তে যে শব্দটি উচ্চারিত হচ্ছে, স্ক্রিনে সেই আরবি শব্দটি **উজ্জ্বল সোনালী দ্যুতি (Golden Glow Aura)** সহ হাইলাইট হয়।
  * সংশ্লিষ্ট সম্পূর্ণ আয়াতটির বর্ডারে সোনালী ফোকাস যুক্ত হয়।
  * **স্মার্ট অটো-স্ক্রোল:** তিলাওয়াতের তালে তালে স্ক্রিন মসৃণভাবে স্ক্রোল হয়ে বর্তমান পঠিত শব্দ ও আয়াতকে চোখের সামনে কেন্দ্রস্থলে রাখে।
  * **ইন্টারেক্টিভ ফ্লোটিং প্লেয়ার বার:** প্লে/পজ, আয়াত জাম্প (`⏮` / `⏭`), গতি নিয়ন্ত্রণ (`0.75x`, `1x`, `1.25x`), টাইম স্ক্রাবার এবং অটো-স্ক্রোল টগল।
  * **ক্লিক-টু-সিক (Click-to-Seek):** যেকোনো আয়াতের স্পিকার আইকনে ট্যাপ করলেই তিলাওয়াত সরাসরি সেই আয়াতের সঠিক সেকেন্ডে জাম্প করে সেখান থেকে বাজতে শুরু করে।

### ৪. ০ মিলিসেকেন্ড ইনস্ট্যান্ট ক্যাশিং (Instant RAM & DOM Retention)
* **মাল্টি-টিয়ার র‍্যাম ক্যাশ:** একবার যেকোনো সূরা বা মেটাডাটা লোড হলে তা মেমোরিতে থেকে যায়; ব্যাক বাটন চাপলে বা শব্দ দেখে ফেরত এলে কোনো লোডিং স্পিনার ছাড়াই **০ মিলিসেকেন্ডে** স্ক্রিন চলে আসে।
* **ডম রিটেনশন (DOM Retention):** শব্দ বিস্তারিত দেখে ফিরে আসার সময় পুরো সূরার শত শত আয়াত পুনরায় রেন্ডার না করে বিদ্যমান স্ক্রিনেই সংরক্ষিত রাখা হয় এবং সংশ্লিষ্ট শব্দটি হাইলাইট করে দেওয়া হয়।
* **ফ্র্যাগমেন্ট রেন্ডারিং:** সূরা বাকারার মতো বড় সূরাগুলোর প্রথম ২৫টি আয়াত সাথে সাথে লোড হয় এবং বাকিগুলো ব্যাকগ্রাউন্ডে মসৃণভাবে রেন্ডার হয়।

### ৫. অফলাইন পিডব্লিউএ ও মেমোরি সুরক্ষা (Persistent Storage Protection)
* **ক্যাশ ক্লিয়ার প্রটেকশন:** অডিও ডাউনলোড ম্যানেজারে আধুনিক Web `navigator.storage.persist()` যুক্ত থাকায় গুগল ক্রোম বা অ্যান্ড্রয়েড সিস্টেম ক্যাশ ক্লিনিংয়ের সময় অডিও ও ডাটাবেজ ফাইলগুলোকে মুছে ফেলতে পারে না।
* **সার্ভিস ওয়ার্কার (Service Worker):** সূরা ডেটা ও সেগমেন্টের ক্ষেত্রে ক্যাশ-ফার্স্ট পলিসি এবং অডিও স্ট্রিমের জন্য ডেডিকেটেড ক্যাশ স্টোরেজ।

### ৬. প্র্যাকটিস, কুইজ ও SM-2 স্পেসড রিপিটেশন
* **১০টি করে শব্দ সেট:** প্রতি সেটে শব্দার্থ মুখস্থ করার পর ফ্ল্যাশকার্ড ও মাল্টিপল চয়েস কুইজ।
* **SM-2 অ্যালগরিদম:** প্রতিটি শব্দের জন্য ইউজার কতটুকু মনে রাখতে পারছে তার ওপর ভিত্তি করে পুনরাবৃত্তির সময় নির্ধারণ (SuperMemo-2 Spaced Repetition)।
* **দুর্বল শব্দ সংগ্রহশালা (Weak Words Deck):** কুইজে ভুল হওয়া শব্দগুলো স্বয়ংক্রিয়ভাবে আলাদা তালিকায় যুক্ত হয় যাতে পরবর্তীতে রিভিশন দেওয়া যায়।
* **বুকমার্ক ও নোটস:** যেকোনো শব্দ বুকমার্ক করে রাখা এবং নিজস্ব নোট লিখে রাখার ব্যবস্থা।

### ৭. সুপাবেস ক্লাউড সিঙ্ক (Supabase Cloud Backup)
* যেকোনো ডিভাইসে ইউজার লগইন করে নিজের প্রোগ্রেস, বুকমার্ক এবং পড়ার অগ্রগতি স্বয়ংক্রিয়ভাবে ক্লাউডে ব্যাকআপ রাখতে পারেন।
* অফলাইনে কাজ করলেও পরবর্তীতে ইন্টারনেট সংযোগ পেলে স্বয়ংক্রিয়ভাবে সিঙ্ক সম্পন্ন হয়।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

| কম্পোনেন্ট | প্রযুক্তি |
|---|---|
| **ফ্রন্টএন্ড কোর** | Vanilla JavaScript (ES Modules), HTML5, CSS3 Custom Tokens |
| **ব্যান্ডলার ও ডেভ সার্ভার** | Vite, Node.js (Port 3000) |
| **লোকাল ডাটাবেজ** | IndexedDB (Database: `QuranVocabDB`, Object stores: surahs, ayahs, words, word_summaries, progress) |
| **অফলাইন আর্কিটেকচার** | Service Worker (`CacheStorage`), Web `navigator.storage.persist()` |
| **ক্লাউড ডাটাবেজ ও অথ** | Supabase (PostgreSQL, Row Level Security, Supabase Auth) |
| **টাইপস্কেকিং ও টেস্ট** | TypeScript, Node Native Test Runner (`node:test`) |
| **ফন্ট ও আইকন** | Amiri, Noto Sans Bengali, IndoPak Nastaleeq, কাস্টম ভেক্টর SVG আইকন |

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টল
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
ব্রাউজারে `http://localhost:3000` ঠিকানায় অ্যাপটি দেখতে পাবেন।

### ৩. ইউনিট টেস্ট চালানো
```bash
npx --yes tsx --test src/utils/recitation-sync.test.ts src/utils/word-audio-gesture.test.ts src/utils/progress-chart-data.test.ts
```

### ৪. প্রোডাকশন বিল্ড তৈরি
```bash
npm run build
```

২. আপনার লাইভ বা প্রিভিউ অ্যাপ ইউআরএল দিয়ে ইনিশিয়ালাইজ করুন:
```bash
bubblewrap init --manifest="https://ais-pre-p2da7ooccypo7hn7xou6cw-689209273818.asia-east1.run.app/manifest.json"
```
৩. সরাসরি সাইনড APK এবং AAB বিল্ড করুন:
```bash
bubblewrap build
```
ফলাফল: আপনার ফোল্ডারে `app-release-signed.apk` প্রস্তুত হয়ে যাবে, যা সরাসরি যেকোনো অ্যান্ড্রয়েড ফোনে ইনস্টল করে ব্যবহার করা যাবে।

### পদ্ধতি ২: Capacitor দিয়ে Android Studio প্রজেক্ট তৈরি
১. Capacitor ইনস্টল করুন:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Quran Vocab" "com.quranvocab.app" --web-dir dist
```
২. প্রোডাকশন বিল্ড করে অ্যান্ড্রয়েড প্ল্যাটফর্ম যোগ করুন:
```bash
npm run build
npx cap add android
npx cap open android
```
৩. Android Studio ওপেন হলে **Build > Generate Signed Bundle / APK** থেকে সরাসরি `.apk` ফাইল এক্সপোর্ট করুন।
