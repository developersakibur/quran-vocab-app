# মুআল্লিমুল কুরআন — কুরআনিক শব্দার্থ, ব্যাকরণ ও তিলাওয়াত শিক্ষা প্ল্যাটফর্ম
### Quran Vocabulary, Morphology & Real-Time Word-Sync Recitation PWA

> **মুআল্লিমুল কুরআন (Quran Vocabulary App)** হলো কুরআনের শব্দে শব্দে বাংলা অর্থ, ব্যাকরণগত মূল ধাতু (Root), পদ প্রকার (Parts of Speech) এবং ক্বারী মিশারি রাশিদ আল-আফাসীর পূর্ণাঙ্গ সূরা তিলাওয়াতের সাথে মিলিসেকেন্ড-ভিত্তিক রিয়েল-টাইম শব্দ সিঙ্ক্রোনাইজেশন (Word-Sync Recitation) শেখার একটি পূর্ণাঙ্গ, আধুনিক ও অফলাইন-বান্ধব প্রগ্রেসিভ ওয়েব প্ল্যাটফর্ম (PWA)।

---

## 🌟 প্রধান প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. ১১৪টি সূরার শব্দে শব্দে বাংলা অর্থ ও ব্যাকরণ (Word-by-Word Morphology)
* কুরআনের সম্পূর্ণ **১১৪টি সূরার ৬,২৩৬টি আয়াত** এবং **৭৭,৪০০+ শব্দের** প্রতিটি অংশের জন্য:
  * বিশুদ্ধ আরবি শব্দ ও ডাবল-লাইন পূর্ণ বাংলা অর্থ (কোনো শব্দ অর্থ `...` দিয়ে কাটা হয় না)
  * বাংলায় সহজবোধ্য ব্যাকরণগত ব্যাখ্যা (লিঙ্গ, বচন, কাল, ই‘রাব, মূল ধাতু ও পদ প্রকার)
  * **একই শব্দ ও একই মূলধাতু তালিকা (Exact-Word & Same-Root Concordance):** শব্দ বিস্তারিত পেজে কুরআনে হুবহু একই শব্দ এবং একই মূলধাতু থেকে গঠিত অন্যান্য শব্দগুলো আলাদা সারণিতে (`আরবী | শব্দার্থ | সূরা:আয়াত:শব্দ`) প্রদর্শন
  * মাক্কী ও মাদানী সূরার জন্য সলিড **কাবা শরীফ** ও **মসজিদ** SVG আইকন
  * ১০০% সলিড ইনলাইন SVG আইকন সিস্টেম ও স্লাইড-আউট সাইডবার মেনু (আরবী ও বাংলা ফন্ট সাইজ ৭৫%–১৬০% কাস্টমাইজেশন ও লাইভ প্রিভিউসহ)

### ২. হোল্ড-টু-প্লে একক শব্দ অডিও ও ট্যাপে বিস্তারিত (Press & Hold Word Audio)
* আয়াতে বা বুকমার্ক তালিকায় যেকোনো আরবি শব্দে **৩৬০ মিলিসেকেন্ড** চেপে ধরে রাখলে (Long Press):
  * সরাসরি সেই একক শব্দের স্পষ্ট উচ্চারণ অডিও চালু হয়
  * স্পর্শানুভূতিপূর্ণ হ্যাপটিক ভাইব্রেশন (`navigator.vibrate`) প্রদান করে
* সাধারণ কুইক ট্যাপে শব্দ বিস্তারিত পেজে নিয়ে যায়; হোল্ড করার সময় পেজ ন্যাভিগেশন স্থগিত থাকে।

### ৩. Tarteel-ভিত্তিক রিয়েলটাইম শব্দ সিঙ্ক ও ফ্লোটিং প্লেয়ার
* ক্বারী **মিশারি রাশিদ আল-আফাসী**-র Tarteel পূর্ণাঙ্গ সূরা তিলাওয়াত (`audio-cdn.tarteel.ai`) ও Quran.com QDC API থেকে ক্যালিব্রেট করা ১১৪টি সূরার মিলিসেকেন্ড টাইমিং (`data/segments/`) ব্যবহার করে:
  * **ইনস্ট্যান্ট ও লেআউট-স্থির শব্দ হাইলাইট:** কোনো অ্যানিমেশন ল্যাগ বা ফন্ট-ওয়েট শিফট ছাড়াই তিলাওয়াতকৃত শব্দ তাৎক্ষণিক হাইলাইট হয় (শব্দের অবস্থান বিন্দুমাত্র নড়ে না), এবং ইতোমধ্যে পঠিত শব্দগুলো সবুজ রঙে চিহ্নিত থাকে।
  * **একক ও ধারাবাহিক আয়াত প্লেব্যাক:** পৃথক আয়াত অডিও ডাউনলোড ছাড়াই Tarteel-এর পূর্ণ সূরা অডিও থেকে সেগমেন্ট টাইমস্ট্যাম্প ব্যবহার করে নির্দিষ্ট আয়াতও সরাসরি বাজানো যায় (অনলাইন ও অফলাইন উভয় ক্ষেত্রে)।
  * **ব্যালেন্সড ফ্লোটিং প্লেয়ার বার:** নিচের বাম পাশে স্পিড কন্ট্রোল (`0.75x`, `1x`, `1.25x`), মাঝখানে পূর্ববর্তী/প্লে-পজ/পরবর্তী বাটন, এবং নিচের ডান পাশে সমান দূরত্বে **অটো-স্ক্রোল টগল SVG বাটন**।

### ৪. বুকমার্ক পেজ ও উন্নত স্মরণ পয়েন্ট (Remember Point)
* **সমান প্রস্থের গ্রিড রো (Equal-Width Columns):** প্রতিটি বুকমার্ক সারিতে আরবি শব্দের ঠিক নিচে সূরা ও শব্দের রেফারেন্স নম্বর, পাশে পরিচ্ছন্ন বাংলা অর্থ, স্মরণ পয়েন্ট এবং অ্যাকশন বাটন সমান প্রস্থের কলামে সারিবদ্ধ থাকে।
* **বৈজ্ঞানিক স্মরণ পয়েন্ট ক্যালকুলেশন (০–১০০%):**
  * **SM-2 Spaced Repetition** (পুনরাবৃত্তি, ইন্টারভ্যাল ও ইজ ফ্যাক্টর)
  * **Bayesian Accuracy** (সঠিক ও ভুল উত্তরের অনুপাত)
  * **Ebbinghaus Forgetting Curve** (`exp(-0.10536 × elapsedDays / stability)`)
  * দুর্বল শব্দের পেনাল্টি ও গড় স্মরণ পয়েন্ট প্রদর্শন
* প্রতিটি শব্দে ক্লিক, অডিও শোনা বা আন-বুকমার্ক করার সাথে সাথেই পরিবর্তন সংরক্ষিত হয়।

### ৫. প্র্যাকটিস হাব, ইন্টারেক্টিভ ফ্ল্যাশকার্ড ও কুইজ
* **সংরক্ষিত শব্দের ফ্ল্যাশকার্ড:** বুকমার্ক করা শব্দগুলোর জন্য Flip-to-Reveal ফ্ল্যাশকার্ড ও ৪-স্তরের নলেজ রেটিং (`আবার`, `কঠিন`, `ভালো`, `সহজ`)।
* **সর্বাধিক ব্যবহৃত শব্দ অগ্রাধিকার ও পূর্ণ কুরআন কাউন্টার:** সূরা বা আয়াত নির্দিষ্ট না করে সরাসরি কুইজ শুরু করলে পূর্ণ কুরআনে সবচেয়ে বেশি ব্যবহৃত শব্দগুলো আগে আসে এবং প্রতিটি MCQ প্রশ্নের ওপরে শব্দটি পূর্ণ কুরআনে মোট কতবার এসেছে তার কাউন্টার দেখায়।
* **ক্যাশযোগ্য পজিটিভ ও এরর সাউন্ড:** সঠিক ও ভুল উত্তর নির্বাচনের সাথে সাথে অফলাইন-ক্যাশযোগ্য অডিও সাউন্ড (`correct.wav`, `wrong.wav`) বাজে।
* **শূন্যস্থান পূরণ ও দুর্বল শব্দ সংগ্রহশালা (Weak Words Deck):** আয়াতের প্রেক্ষাপটে শূন্যস্থান পূরণ এবং ভুল হওয়া শব্দগুলোর পুনরাবৃত্তি ডেক (পরপর ২ বার সঠিক উত্তর দিলে পুনরুদ্ধার হয়)।

### ৬. একাউন্ট ড্যাশবোর্ড, ফুল-পেজ অথ ও সুপাবেস ক্লাউড সিঙ্ক
* বটম ন্যাভিগেশন বারের ৪র্থ **একাউন্ট** ট্যাবে পপ-আপ ছাড়াই পূর্ণাঙ্গ সাইন-ইন, সাইন-আপ ও ইমেইল ভেরিফিকেশন পেজ (`emailRedirectTo` সহ)।
* লগইন করা ইউজারের নাম, ইমেইল, প্রগ্রেস সারসংক্ষেপ, **দৈনিক অনুশীলন স্ট্রিক ক্যালেন্ডার (Daily Streak Calendar)** এবং **৩০ দিনের D3 প্রগ্রেস চার্ট**।
* প্রতিটি অনুশীলন ও বুকমার্ক পরিবর্তন IndexedDB, LocalStorage এবং লগইন করা ইউজারের **Supabase** একাউন্টে (`user_progress`, `user_bookmarks`) স্বয়ংক্রিয়ভাবে সিঙ্ক হয়।

### ৭. ডেডিকেটেড অফলাইন অডিও ম্যানেজার ও প্যারালাল ডাটা ডাউনলোডার
* ডিভাইস ও নেটওয়ার্কের সক্ষমতা অনুযায়ী **প্যারালাল কনকারেন্সি (Parallel Worker Pool)** ব্যবহার করে ১১৪টি সূরার সব শব্দ, বাংলা অর্থ, ব্যাকরণ ও সেগমেন্ট টাইমস্ট্যাম্প দ্রুত অফলাইনে সংরক্ষণ।
* আলাদা পূর্ণাঙ্গ **অডিও ম্যানেজার পেজ** (`#downloads`), যেখানে রিয়েল-টাইম ডাউনলোড শতাংশ (`%`) এবং কেবল এই PWA অ্যাপের প্রকৃত **ব্যবহৃত স্টোরেজ (MB)** আপডেটসহ Tarteel সূরা ও একক শব্দ অডিও সমান্তরালভাবে সংরক্ষণ করা যায়।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

| কম্পোনেন্ট | প্রযুক্তি |
|---|---|
| **ফ্রন্টএন্ড কোর** | Vanilla JavaScript (ES Modules), HTML5, CSS3 Design Tokens |
| **ব্যান্ডলার ও ডেভ সার্ভার** | Vite, Node.js (Port 3000) |
| **লোকাল ডাটাবেজ** | IndexedDB (`QuranVocabDB` v2: `surahs`, `ayahs`, `words`, `word_summaries`, `word_progress`, `weak_words`, `bookmarks`, `notes`, `activity`, `lookup`) |
| **অফলাইন আর্কিটেকচার** | Service Worker (`sw.js`, `CacheStorage`), `navigator.storage.persist()` |
| **চার্ট ও ভিজ্যুয়ালাইজেশন** | D3.js (`js/progress-chart.js`) |
| **ক্লাউড ডাটাবেজ ও অথ** | Supabase (PostgreSQL, Row Level Security, Auth) |
| **টাইপ-চেকিং ও ইউনিট টেস্ট** | TypeScript (`tsc --noEmit`), Node Native Test Runner (`node:test`) + `tsx` |
| **ফন্ট ও আইকন** | Amiri, Noto Sans Bengali, IndoPak Nastaleeq, কাস্টম সলিড SVG আইকন |

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টল
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
ব্রাউজারে `http://localhost:3000` ঠিকানায় অ্যাপটি চালু হবে।

### ৩. ইউনিট টেস্ট ও টাইপ-চেক চালানো
```bash
npx --yes tsx --test src/utils/*.test.ts
npm run lint
```

### ৪. প্রোডাকশন বিল্ড তৈরি
```bash
npm run build
```

## 📱 অ্যান্ড্রয়েড ইনস্টলার (APK) তৈরির গাইডলাইন

এই PWA প্ল্যাটফর্মটিকে ফোনের নিজস্ব আলাদা অ্যান্ড্রয়েড অ্যাপ (`.apk`) হিসেবে রূপান্তর করতে পারেন:

### পদ্ধতি ১: Google Bubblewrap (TWA)
```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest="https://ais-pre-p2da7ooccypo7hn7xou6cw-689209273818.asia-east1.run.app/manifest.json"
bubblewrap build
```

### পদ্ধতি ২: Capacitor দিয়ে Android Studio প্রজেক্ট তৈরি
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Quran Vocab" "com.quranvocab.app" --web-dir dist
npm run build
npx cap add android
npx cap open android
```
